# Telegram-клиент на GREEN-API

Минимальный веб-клиент для обмена личными текстовыми сообщениями Telegram через GREEN-API. Интерфейс вдохновлён Telegram Web: светлая тема, список чатов и активная переписка.

## Стек

- React 19, TypeScript, Vite.
- CSS Modules, Lucide React.
- Нативный Fetch API, HTTP long polling, AbortController, Web Locks.
- ESLint.

## Локальный запуск

Требуются Git, Node.js 24 и npm. Склонируйте репозиторий, установите зависимости и запустите приложение.

```bash
git clone https://github.com/tochistyakov/green-api-test.git test-chistyakov
cd test-chistyakov
npm ci
npm run dev
```

Откройте адрес, указанный Vite в терминале. В форме подключения введите `apiUrl`, `idInstance` и `apiTokenInstance` авторизованного Telegram-инстанса из личного кабинета GREEN-API.

Для получения сообщений в настройках инстанса (ЛК GREEN-API) оставьте `webhookUrl` пустым и включите `incomingWebhook`. Для статусов отправки включите `outgoingWebhook`, `outgoingMessageWebhook`, `outgoingAPIMessageWebhook`; для событий авторизации — `stateWebhook`.

## Реализованные возможности

- Проверка подключения через `GetStateInstance`, показ и скрытие токена.
- Создание чатов по телефону России/Беларуси или `@username` через `CheckAccount`, без дублирования чатов.
- Поиск по локальному списку чатов.
- Отправка текста до 4096 символов: Enter — отправить, Shift+Enter — новая строка.
- Статусы отправки, доставки и прочтения; ручной повтор при ошибке запроса.
- Получение новых личных текстовых сообщений через последовательный long polling, подтверждение уведомлений и защита от дубликатов.
- Обработка ошибок сети, авторизации и API; задержки между повторными попытками polling.
- Адаптивный интерфейс от 320 px, перенос длинного текста и автопрокрутка с учётом ручной прокрутки.
- Отключение с отменой запросов и очисткой состояния сессии.

## Особенности

Токены, чаты и сообщения хранятся только в памяти страницы и сбрасываются после перезагрузки. История переписок не загружается. Имена и аватарки пользователей не загружаются. Поддерживается только текстовая личная переписка. Используйте одну активную вкладку на инстанс.
